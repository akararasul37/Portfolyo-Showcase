# ⚔️ Ahmed Kararasul | Modern & Asil Portfolyo

Bu depo, modern web teknolojilerini asil ve medieval (orta çağ) esintili bir tasarımla birleştiren kişisel portfolyo sitemi barındırmaktadır. "Dijital Krallığım" konseptiyle hazırlanan bu proje, hem teknik yeteneklerimi hem de tasarım vizyonumu sergilemektedir.


## ✨ Özellikler

*   **🛡️ Özgün Geçiş Efektleri:** Sayfalar arası geçişte kılıç kesme (Sword Slash) animasyonu.
*   **🌌 Dinamik Arkaplan:** Etkileşimli parçacık (particle) sistemi ve imleç takibi yapan ışık efekti.
*   **🃏 3D Kart Deneyimi:** Projeler bölümünde jiroskopik (tilt) efektli 3D kart tasarımları.
*   **⚡ Performans Odaklı:** Hızlı yükleme süreleri için optimize edilmiş varlıklar ve özel preloader.
*   **📱 Tam Duyarlı Tasarım:** Mobil, tablet ve masaüstü cihazlar için mükemmel uyum.
*   **🎭 İnteraktif Modallar:** Proje detaylarını incelemek için şık modal pencereleri.

## 🛠️ Kullanılan Teknolojiler

*   **Front-End:** HTML5, CSS3 (Vanilla), JavaScript (ES6+)
*   **Tasarım:** Custom CSS Variables, Flexbox, Grid, CSS Animations
*   **Varlıklar:** Google Fonts (Inter, Playfair Display), Custom SVG Icons
*   **Konsept:** Medieval / Noble Dark Mode Aesthetic

## 📂 Proje Yapısı

```text
├── css/

```
